## Key Learnings
1. Functional testing confirms logical correctness for an individual user, but performance testing is essential to discover how the system holds up under concurrent users and stress.
2. Knowing how `PATH` and command-line redirection work saves a lot of troubleshooting time when working with tools like JMeter, Git, and test automation frameworks.
3. Work committed locally is only on your machine—pushing to the remote repository is what makes it visible for peer reviews, automated CI pipelines, and deployments.
